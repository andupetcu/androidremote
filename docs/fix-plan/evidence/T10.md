## What changed
- New `mdm/telemetry/TelemetryBuffer.kt`: `SampleRingBuffer` (file JSONL, 1000 cap, atomic rewrite on trim/drop), `TelemetryFlusher` (oldest first, remove only after server accepts, batch of 100, single post when only one sample, 404 fallback remembered), `ReportInterval`/`ReportSchedule` (default 60 s, clamp 15 s..1 h), `LocationPolicy` (max age 15 min, requested only if location enabled and permission granted).
- `TelemetryCollector`: every report appends a timestamped sample (`collectedAt` added to `TelemetryData`) and flushes the queue. `POST /telemetry/batch` body is `{"samples":[...]}`. The single endpoint's `nextReportIn` updates `schedule`. New `reportIfDue(serverUrl, deviceId)`. The forever `cachedLocation` is gone; location is a fresh `getCurrentLocation` (API 30+, 5 s timeout) plus last-known fixes, filtered by age on every read, else null.
