## What changed
- `lib/screenGeometry.ts` (new, pure): object-fit contain box math and pointer-to-screen mapping (reject bars, optional clamp).
- `lib/FrameDecoder.ts`: `onError`, `onKeyframeNeeded` (rate limited), `onFrameRendered`; async decoder errors rebuild the decoder and wait for an IDR; deltas are never buffered before the first keyframe; backlog (`decodeQueueSize > 3`) drops deltas, and a keyframe during a backlog resets the decoder; chunk reassembly capped at 8 sets / 8 MiB, aged out at 2 s, older incomplete sets dropped when a newer frame completes (gap, so resync); latest-frame-wins painting through requestAnimationFrame; console logging removed.
- `hooks/useWebRTC.ts`: ICE servers from the server (STUN-only fallback), hard-coded TURN credentials removed; `commands` + `video` channels; single message demux; new result fields `screenInfo`, `captureError`, `devicePresent`, `subscribeVideo`, `requestKeyframe`; signaling close / error / 20 s timeout reported via a ref (fixes the stale `onclose` closure); command timers cleared and pending commands rejected on ack, disconnect and unmount; ICE / command console logging removed.
- `components/RemoteScreen.tsx`: letterbox- and rotation-aware coordinates (SCREEN_INFO, else decoded size, else element box); pointer capture, cancel and lost-capture handling, `touch-action: none`; no `onmessage` override; error / stall / CAPTURE_FAILED overlay (`role="alert"`); stall watchdog (3 s) requests a keyframe; console logging removed.
- `components/RelayRemoteScreen.tsx`: ordered tile drawing (decode concurrently, draw through a promise chain); mouse-move coalescing per animation frame; key / button release on blur and mouse leave; auto reconnect with backoff (each connect fetches a fresh ticket), stopped by user Disconnect or unmount.

Also WU-10 "retry / ICE restart" UX is not done (only the connect-failure message).

- `src/tests/mocks` (not owned): `wsAuth.test.tsx` (T5) now triggers an unhandled `GET /api/ice-servers` that MSW logs as an error. It is caught by the fallback and the test passes; adding a default handler in `mocks/handlers` would silence it.
