# T19: remote desktop is rooted-only

Owner decision: remote desktop supported on rooted devices only.

## Tests (written first)
- `ScreenCaptureControllerTest`: `no working root fails fast with root_required and never retries` (replaces the consent_required test): one report, no streams, no restart, nothing after 120 s of virtual time.
- `RootProbeTest` (3): uid=0 means root; su missing/denied/IOException means no root; positive cached, negative re-probed after 30 s.
- `RemoteDesktopGateTest` (2): START_REMOTE refused with "Remote desktop requires a rooted device" when not rooted.
- `RootedTelemetryTest` (1): `rooted` serialised in TelemetryData.

## Removed
- `ScreenCaptureRequestActivity`, `ScreenCaptureService` (prompt/notification) and their manifest entries.
- Manifest: `FOREGROUND_SERVICE_MEDIA_PROJECTION`; RemoteSessionService foregroundServiceType is now `specialUse` only.
- `RemoteSessionService`: consent receiver, `requestScreenCapturePermission`, `startScreenCapture` (MediaProjection), `screenCaptureManager`, `consent_required` -> promptIntent branch.
- `CaptureFailureReason.CONSENT_REQUIRED` (now `ROOT_REQUIRED = "root_required"`).
## Kept
- `CommandPollingService.executeTakeScreenshot`: did not use MediaProjection (stub); message changed to "Screenshot is not supported".
- `feature-screen` module (`ScreenCaptureManager`, `H264Encoder`, `ScreenCapturerFactory`, `AdbScreenCapturer`): library code no longer referenced by the app; left untouched (separate module, own tests). Candidate for later removal.
- `SessionController.reportCaptureFailed` / `publishScreenInfo`: still used by the screen-server path.

## Behaviour
- `ScreenCaptureController`: no working root -> reports `root_required` once and the supervisor ends (no retry). Other reasons keep the backoff. A running adb-started server no longer rescues a non-root device (owner decision). Root check is now `RootProbe` (`su -c id` shows uid=0, 5 s timeout, off the main thread via `Dispatchers.IO`), not just "su file exists". `CaptureBackend.isRooted` is now `suspend`.
- START_REMOTE: `executeStartRemote` probes root (IO) and fails the command with "Remote desktop requires a rooted device" before any service starts.
- Telemetry: `rooted: Boolean?` from `RootProbe.shared` (cached; collectTelemetry already runs off Main).
