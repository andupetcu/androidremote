## What changed, per finding
- AR-02: new `ShellCommands` builds argv only. `su 0 input text <arg>` (Toybox su runs argv without a shell), `input text <arg>` without root. Control chars (\n \r \t NUL) are stripped, spaces become `%s`. For Magisk `su -c` (which does parse a string) every argument is POSIX single-quoted. tap/swipe/keyevent are built from ints/longs only. `sh -c` is gone. Only `runShellCommand` callers were in AdbShellInjector.
- AR-16: new `ShellProbe`. On Main it never execs: it schedules a background probe and returns the last answer. Positive results are cached. Negative results are retried after 30 s. `AdbShellInjector` warms the probe in `init`, and its suspend methods run the probe on IO. `InputHandler` now re-evaluates availability on each use. `InputInjectorFactory` returns the shell injector even while the first probe is pending.
- AR-08: Server accepts only the uid given by `-u <uid>`, from `LocalSocket.peerCredentials`. Without `-u` it rejects everyone (fail closed). `ScreenServerClient` also checks that the server peer uid is shell (2000), root (0) or the app itself.
- AM-14: `EnrollmentIntentGuard` (pure). Extras are ignored when enrolled or invalid (token missing, URL not http/https with host). Launched-from uid shell/root/self is accepted. Anything else, or unknown, shows a confirmation dialog with the server URL. Caller uid comes from `Activity.getLaunchedFromUid` via reflection (hidden API); null on failure, which means confirmation is required.
- AM-15: `allowBackup="false"`, and both backup rule files now exclude everything. `SecurePrefsResolver`: on failure, reset the store and retry once, then use in-memory prefs (fail closed, error logged). No plaintext fallback file. The old `session_prefs_fallback` file is deleted at startup. `SessionStorage.isSecureStoragePersistent` exposes the state; a UI to show it is not added (see below).
- AM-06/AR-17: main `network_security_config.xml` is HTTPS only; fake subnet entries removed. `app/src/debug/res/xml/network_security_config.xml` allows cleartext for debug builds only. A network security config cannot read string resources, so a `server_cleartext_hosts` resource cannot feed it directly. The release file documents the supported way: add exact host names as `<domain>` entries. No range entries.
- AR-18/AM-23: `LogRedactor` (secret, typedText, url, scrub). Removed token from MainActivity log, URL logs redacted, SessionStorage per-read debug logs removed, AdbShellInjector no longer logs command text.
