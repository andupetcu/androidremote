## What changed
- New `kiosk/`: KioskPolicy (parse/plan), KioskWatchdog, MaintenanceWindow/UpdatePolicy, BootPlan, ProtectedPackages, WipeGuard, GrantStates, PolicyUpdate, BootAppsMerge, BootApps (prefs), AppManagement, KioskController, TargetPackageReceiver.
- AM-07: SET_KIOSK -> `setLockTaskPackages([pkg, own])`, `setLockTaskFeatures(NONE)`, `setKeyguardDisabled`, `setStatusBarDisabled`; target started in lock task with `ActivityOptions.setLockTaskEnabled(true)` (replaces the trampoline activity: it works for a third-party target, `startLockTask()` from our own activity would pin only our task). With lockTask=false: `addPersistentPreferredActivity` for HOME (target needs a HOME activity, otherwise a clear failure). Kiosk record in device-protected storage. Watchdog `kioskController.watchdogTick()` every poll, 30 s cooldown; foreground detected through UsageStats (device owner tries to self-grant PACKAGE_USAGE_STATS; when unknown, the target counts as not in front and is relaunched on cooldown).
- AM-08: PACKAGE_ADDED/REPLACED receiver registered dynamically by the service (manifest registration of these is not reliable on O+); auto-update relaunches the target after install; installs wait for a maintenance window (`updateWindow {start,end}` "HH:mm" in SYNC_POLICY; absent window = immediately). Not done: per-package failure backoff (1h/6h/24h) and server-side staged rollout.
- AM-09: SYNC_POLICY changes only carried fields; `requiredApps` rebuilds `boot_apps` in one step; uninstall removes the entry; SET_KIOSK enabled=false removes it.
- AM-10: one receiver `mdm.BootReceiver` (directBootAware, LOCKED_BOOT_COMPLETED + BOOT_COMPLETED), order from BootPlan; `admin.BootReceiver` deleted and removed from the manifest; no RemoteSessionService or MainActivity start from boot or from PackageUpdateReceiver; service init is idempotent.
- AM-16: UNINSTALL/DISABLE refuse self and protected packages; WIPE needs `confirm == deviceId`; external storage wiped only with `wipeExternalStorage:true`. Not done: audit event / reason field (server side).
- AM-17/C10: DISABLE_APP/ENABLE_APP (`setApplicationHidden`), LAUNCH_APP, GRANT_PERMISSION, SET_PROTECTED_PACKAGES.
- AM-24: removed the Settings.Secure write; DISALLOW_ADJUST_VOLUME while silent so volume keys do not undo the mute. DND access needs `adb shell cmd notification allow_dnd com.androidremote.app` once.
- Follow-ups: MainActivity shows "Enrollment invalid" plus reason, does not restart the service while invalid, clears the flag on re-enrolment and on reset; polling uses `telemetryCollector.reportIfDue` on every poll (the every-6th-poll counter now only drives the update check); `ScreenServerManager.prestart(false)` on boot and `prestart(true)` after self-update, off Main, failures logged.
