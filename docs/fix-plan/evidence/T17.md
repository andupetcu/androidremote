## Changes
- `appSyncService.queueKioskCommand`: queues `SET_KIOSK {packageName, enabled, lockTask:true}` (policies have no lock-task
  field), `supersede: 'type'` so an older pending one expires. Called wherever SYNC_POLICY is queued: policy assign
  (`PUT /api/devices/:id/policy`), policy edit (now also triggered by a kioskPackage change). Audit: only these two
  SYNC_POLICY sites exist. Moving a device off a kiosk policy (other policy or unassign) queues enabled:false for the
  previous kiosk package. Nothing is queued when no package is known (kiosk needs one; kioskMode without kioskPackage is skipped).
- `agentConnectionStore.disconnectDevice`, `relay.disconnectRelayDevice`, `signaling.disconnectDevice(deviceId, reason)`:
  close signaling peers (device + controller), relay agent and relay viewers (code 4004), clear room/agent state.
  `DELETE /api/devices/:id` calls it; sessions are removed by the FK cascade (token stops working).
